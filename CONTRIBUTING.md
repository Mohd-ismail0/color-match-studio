# Contributing to ColorFix

Thanks for helping improve ColorFix! This guide covers how to get set up and
how we prefer contributions to be submitted.

## Development setup

1. Fork and clone the repo.
2. Install dependencies.

```sh
npm install
```

3. Start the dev server.

```sh
npm run dev
```

## Code quality

Before submitting a change, please run:

```sh
npm run lint
npm run test
```

If you add new functionality, please add tests where it makes sense.

## Commit messages

Use clear, descriptive commit messages. Keep each commit focused on a single
change.

## Pull requests

- Keep PRs small and focused.
- Describe what changed and why.
- Include screenshots or recordings for UI changes.
- Link related issues if applicable.

## Code of Conduct

By participating, you agree to uphold the
[Code of Conduct](CODE_OF_CONDUCT.md).
