# Security Policy

## Supported Versions

We support the latest release on the default branch. Security fixes are applied
there first.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Instead, use GitHub Security Advisories to report issues privately to the
maintainers.

If you are unable to use GitHub Security Advisories, contact a repository
admin through a private channel with a detailed report and reproduction steps.
